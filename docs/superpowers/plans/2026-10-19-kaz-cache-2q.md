# kaz キャッシュの 2Q と compaction の出力の扱い 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `--cache-eviction kaz-2q` を選んだときに、ディスクキャッシュを新入り用と常連用に分ける。あわせて、追い出し済みリストと再起動を越える管理ファイルを持たせ、compaction の読み込みと出力をユーザーの読み書きと区別する。

**Architecture:**
- 判断と状態は kaz のファイルに置く。
  - `pkg/chunk/cache_eviction_2q_kaz.go`：新しい `KeyIndex` の実装 `kaz2QIndex`
  - `pkg/chunk/disk_cache_kaz.go`：cacheStore との接続と管理ファイル
  - `pkg/chunk/cached_store_kaz.go`：compaction の読み込みと出力
  - `pkg/vfs/compact_cache_kaz.go`：出力のブロックと元のブロックの対応
- upstream 由来のファイルには、呼び出しの差し替えと1行の hook だけを入れる。
- kaz の追加機能は、型アサーションで探す optional interface で呼ぶ（既存の `retireCache` と同じ流儀）。

**Tech Stack:** Go（`GOENV_VERSION=1.25.11`）、prometheus client、testify `require`／goconvey（既存のテストに合わせる）。

**Spec:** [docs/superpowers/specs/2026-10-19-kaz-cache-2q-design.md](../specs/2026-10-19-kaz-cache-2q-design.md)

- オプション（既定値）
  - `--kaz-cache-probation-ratio 0.4`：新入り用の取り分。0 < x < 1。範囲外なら Warn して 0.4。
  - `--kaz-cache-promote-delay 10m`：相関期間。0 以上。

- staging（size<0）は、追い出さず、領域の容量にも数えない。
- 管理ファイルの読み書きの失敗は Warn と metrics にとどめ、キャッシュの読み書きの結果には影響させない。容量不足や実保存の失敗を隠す変更（既存のエラー処理の握りつぶし）はしない。

## Review Focus

- **compaction とユーザーが同じブロックを同時に読む場合：** singleflight で compaction の印が付いた読み込みを共有すると、ユーザーの読み込みでもキャッシュに入らないことがある。データは正しく返ること（Task 5 のテスト）。

- **無改良版との往復：** kaz-2q で使ったディレクトリを lru で mount しても全ブロックが見え、管理ファイルは無視される。逆に lru の後に kaz-2q で mount すると、古い管理ファイルの記録の無いブロックは新入り用になること（Task 4、Task 7 のテスト）。

**動き（spec の 5.1〜5.5）。** テストで決まらない点だけを書く。

- **各項目が持つもの**：`cacheItem`（size、atime：ユーザーが最後に読んだ時刻）、`seg`、`inserted`（新入り用に入った時刻。相関期間の起点）、`order`（新入り用での並び順の時刻）、`origin`、`hits`（uint8、上限で止める）。
- **領域の中の並び順**：新入り用は `order`、常連用は `atime` の古い順に並べる。2つの min-heap で持ち、staging（size<0）は map にだけ置く。
- **`add`（新しい key）**
  - size<0 なら新入り用（staging）に置き、origin は write。
  - `expect` にあれば、その区分と atime で入れ、origin は compaction。
  - restore にあれば、保存されていた全項目を戻す。
  - 追い出し済みリストにあれば、常連用に入れて ghost_hit を数え、リストから消す。
  - どれにも当たらなければ新入り用に入れる（`inserted = order = item.atime`）。origin は、`item.atime >= now-60` なら fill、それ以外は legacy（scan で見つけた既存のブロック）。
- **`add`（既存の key）**：size だけを更新し、区分は変えない。size が負から正に変わったとき（アップロード完了）は、新入り用の heap に入れ、`inserted = order = now` とする。
- **`get`（ユーザーのヒット）**
  - `atime = now`、`hits++` とし、origin ごとのヒットを数える。
  - 新入り用で、かつ `now - inserted >= promoteDelay` のときは常連用に移し、promote を数える。それ以外は `order = now` とする。
  - staging は昇格させない。
- **`evictionIter`**（`capacity == 0` なら常連用の上限は無し）
  1. 常連用の容量（size の合計）が `capacity*(1-ratio)` を超えている間は、常連用の atime が一番古いものを新入り用へ移す（`order = inserted = now`、demote を数える）。
  2. 新入り用の `order` が一番古いものを map と heap から消し、追い出し済みリストに入れてから yield する。
  3. 新入り用が空なら、常連用の一番古いものを同じように扱う。両方とも空なら終わる。
- **追い出し済みリスト**：key と size を FIFO で持ち、size の合計が `capacity*ghostRatio` を超えたら古いものから捨てる。ghostRatio が 0 なら何もしない。
- **`remove`**（retire・期限切れ）：追い出し済みリストには入れない。
- **`reset`**
  - 自分を空にし、それまでの項目を、`peekAtime` に答える snapshot として返す。
  - それまでの項目の区分などは restore に移す。前回の restore が管理ファイルから読んだものなら、それと合わせる（いまの項目を優先する）。それ以外の古い restore は捨てる。
  - 追い出し済みリストと設定は残す。
  - `expect` は10分より古いものを捨てる。
- **`kazPlacement`**
  - 渡された key のどれかが常連用にあれば、常連用を返す。
  - 新入り用（staging を含む）にしか無ければ、新入り用を返す。
  - atime は、ある key の中で最大のものを返す。
  - 一つも無ければ `ok=false` を返す。

**形式（agent の判断）**
- little endian の binary で、先頭は magic `"KAZ2QST1"`、続いて `version uint32 = 1`、`savedAt uint32`。
- 項目は、件数（uint32）の後に `id u64, indx u32, size i32, seg u8, origin u8, hits u8, atime u32, inserted u32, order u32` を並べる。
- 追い出し済みリストは、件数（uint32）の後に `id u64, indx u32, size u32` を古い順に並べる。
- 末尾に、それより前の全体の CRC32（IEEE）を付ける。
- 書き込みは `<path>.tmp` に書いて fsync し、rename してから、ディレクトリを fsync する。
- magic・version・長さ・CRC のどれかが合わなければ、エラーにして無視する（state_load_failed）。

**保存と読み込みのタイミング**
- `kazAttach` は、ファイルがあれば読んで `kazImportState` する。その後 `KazCacheStateInterval` ごとに `kazSaveState` する goroutine を、`cache.available()` の間動かす。
- 起動時の `scanCached(true)` は `reset` を呼ぶ。その前に import した restore は、Task 2 の決まりで1回の `reset` を越えて残る。
- 強制終了の経路（SIGHUP、30秒の umount 待ちの後の exit）では保存しない。直近の定期保存に頼る。
